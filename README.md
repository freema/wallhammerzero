# Wallhammer Zero

A custom general-purpose 3D engine in C17 on top of SDL3 and SDL_GPU for large worlds: a city, a planet and strategy games. All graphics (models, materials, animation and the world itself) are generated by code.

Status (2026-11-06): the analysis is closed and the plan is written. No code exists yet. The first step is milestone M0.
